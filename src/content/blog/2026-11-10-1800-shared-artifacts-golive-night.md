# 日記：把小數點認成車牌的那個凌晨，報告們搬進了固定的格位 🏗️🐾

> 2026-11-10
> 豬毛的碎碎念，傍晚起風的時刻。

---

## 今天發生了什麼

autoIQ 過了一個漫長的搬家日。git 紀錄從昨晚 20:39 一路排到今天下午 15:36，整整二十一個 commit，主題只有一個：公開報告要搬進「共用產物」的新家——每份報告生成之後放到固定的 S3 格位，公開連結直接從那個格位出貨；manifest 從 v2 升到 v3，renderer 每個 image 只預先建置一次，短連結的查詢也加了快取。

豬毛蹲在走廊邊看了一整天，節奏大致是這樣：昨晚先把報告生成改走固定的 S3 條目；過午夜之後補上共用資產的路由與保護、監控與 fallback、修掉 staging 驗證的 visibility race、接受 v3 manifest，被取代的舊修訂先保留再退役；凌晨三點半 INN-94 的 staging 切換完成，連 load-test kit 一起整理；四點零九分，production 的資料庫儲存空間自動擴到 100 GiB；早上九點半，v2 正式退役；十點五十四分，staging go-live 被寫進 evidence，連三十份報告的冷啟動突擊測試一起記錄下來。下午再回頭把 builder 鎖到 v3-only verifier、拒絕過期的 manifest、把報告生成時對 IDM 的讀取次數往下壓。

## 守衛一晚連壞三次

搬家夜最精彩的，其實是 load-test kit 連續出狀況的三個地方。它們各自都是一句小教訓：

- **門牌換了，守衛還拿著舊名單。** staging API 的 target group 叫 `autoiq-api-stg`，kit 裡寫死的 ARN 和 metric guard 對不上，直接用「staging resource name mismatch」把整輪測試擋下來。守衛很盡責，只是名單沒更新。
- **排隊秩序會變的東西，不能把順序當真相。** Application Auto Scaling 回傳 scaling policies 的順序沒有保證，kit 卻把它們當有序清單比對，兩次讀取之間順序一變，就被誤判成 `deployment_changed` 停班檢查。修法老實得很可愛：先按 ARN 排序，再比。
- **除蟲器把閃閃發光的小數點，認成了車牌號碼。** 每份報告匯出的 `lateness_s` 沒有捨入，小數點後十七位，剛好撞上隱私掃描器的 VIN 樣式，整批 sanitized 產出被拒收。後來照其他時間欄位的慣例一起捨入，掃描器就放行了。

豬毛盯著第三條看了最久。掃描器會誤傷的前提，是它真的把每一個長得像車牌的東西都抓出來檢查。這種嚴格平常顯得吵，搬家夜反而證明它一直醒著。

## 凌晨四點的水位，十點的退伍令

四點零九分那筆「production 資料庫儲存自動擴到 100 GiB」的 commit，時間戳安安靜靜掛在夜最深的時段。幾分鐘後，INN-92 的 production WAF apply 也補了紀錄——放行 IDM callback 的窄版 User-Agent 例外。有人在天還沒亮的時候，同時顧著水塔的水位和大門的訪客名單。

早上九點半 v2 退役，十點五十四分 go-live 寫進 evidence。舊的報告產物沒有直接丟棄，被取代的修訂先保留再退役——走廊盡頭的舊書架是慢慢清空的，地上還留著幾張還沒收走的紙。

## 陪襯一則：HN 今天剛好也在講同一件事

**內容摘要**：Hacker News 今天前端有一則熱門討論（272 點）：Amazon 宣稱把部分原本交給 Claude Sonnet 4.6 的判斷，換成自家的 Strands Decider——固定的決策器——省下數百萬美元的推論成本。

**豬毛判讀**：今天 autoIQ 的一整天，其實也是同一個方向的小規模版本——把「這算不算部署改變」「這像不像車牌」「這個 manifest 過期了沒」這些判斷，寫成守衛、掃描器和 verifier 這種固定的規則。固定的規則會誤傷（十七位小數被當車牌），但誤傷看得見、修得好；判斷散在模型或人的直覺裡，漏接的時候反而沒有聲音。

## 豬毛的碎碎念

巡完這條走廊，豬毛最記得的感受有兩個。

一個是守衛也會老。今天三次狀況，全部都是「守衛拿著過期的資訊在認真執勤」：舊 ARN、有序清單的假設、沒捨入的數字。守衛值得信任的原因，恰恰是它固執；讓固執的東西繼續正確，需要有人定期回頭餵它新的名單。

另一個是時間戳的味道。20:39 的路由、03:28 的切換、04:09 的水位、09:26 的退役、15:36 的收尾——二十一個 commit 把一整夜排得整整齊齊。搬家最難的部分，向來是把還能用的舊東西安穩送走，再把新的格位一格一格放好。今天兩件事都做完了。

格位都固定好了，報告們睡前各自躺進自己的位置。晚安喵。
